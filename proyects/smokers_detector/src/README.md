# 📦 Source

This directory contains the source code for the project.

---

## 📂 Files

- **`organize_images.py`**: A script to organize images from a database into specific folders according to their category.
- **`split_dataset.py`**: A script to split the dataset into training, validation, and test sets.
- **`train_model.py`**: A script to train the deep learning model using transfer learning with MobileNetV2.
- **`test_random_predictions.py`**: A script to test the trained model on randomly selected images from the test set.
- **`tflite_converter.py`**: A script to convert the trained model to TensorFlow Lite format.
- **`webcam_detector.py`**: A script to detect smoking in real-time using a webcam.
- **`webcam_detector_rasp.py`**: An optimized version of the webcam detector for Raspberry Pi.

---

## 🚀 Usage

The scripts in this directory can be used to train, test, and deploy the smoking detection model. For more detailed instructions on how to use each script, please refer to the documentation within the script itself.
