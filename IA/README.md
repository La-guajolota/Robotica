# 🧠 Artificial Intelligence

This directory contains Artificial Intelligence algorithms and examples.

---

## 📂 Files

- **`ex_ann_1.py`**: A simple Artificial Neural Network (ANN) for recognizing handwritten digits from the MNIST dataset.

---

## 🚀 Usage

To use the script in this directory, you can run it from the terminal:

```bash
python3 IA/ex_ann_1.py
```

This script requires the following libraries: `tensorflow`, `numpy`, `pandas`, `matplotlib`, and `seaborn`.
