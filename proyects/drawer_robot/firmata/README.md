# 펌웨어(Firmware)

This directory contains the firmware for the microcontroller, based on PlatformIO.

---

## 📂 Files

- **`platformio.ini`**: The configuration file for the PlatformIO project.
- **`src/main.cpp`**: The main source code for the firmware, which uses the Firmata protocol to communicate with a host computer.
- **`.gitignore`**: A gitignore file to exclude the `.pio` and `.vscode` directories from version control.
- **`include/` and `lib/`**: Directories for including libraries and other source files.
- **`test/`**: A directory for tests.

---

## 🚀 Usage

This firmware can be compiled and uploaded to a microcontroller using PlatformIO. To do so, you need to have PlatformIO installed.

Once installed, you can open this directory in Visual Studio Code with the PlatformIO extension and use the PlatformIO commands to build, upload, and monitor the firmware.
