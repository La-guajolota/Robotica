# 👁️ Vision

This directory contains computer vision algorithms and examples.

---

## 📂 Files

- **`botones_segment.py`**: A script that segments black circles from an image.
- **`convoluciones.py`**: A script that applies different image filters (convolution kernels) to an image and displays the results.
- **`btns0.jpeg`, `btns1.jpeg`, `btns2.png`, `nadejo.jpeg`**: Images used for testing the scripts.
- **`convoluciones.txt`**: A text file with information about convolutions.
- **`practicas/`**: A directory containing practice notebooks and scripts.

---

## 🚀 Usage

The Python scripts in this directory can be run from the terminal to see the results of the computer vision algorithms. Make sure you have the required libraries installed, such as OpenCV and Matplotlib.
