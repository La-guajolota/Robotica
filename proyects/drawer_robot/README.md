# 🎨 Drawer Robot

This project is for a drawing machine that uses computer vision and ROS2.

---

## 📂 Subdirectories

- **`CAD_tests/`**: Contains CAD files for the robot, including OpenSCAD and URDF files.
- **`firmata/`**: Contains the firmware for the microcontroller, based on PlatformIO.
- **`my_car_ws/`**: A ROS2 workspace for the robot's control and simulation.
- **`urdf/`**: Contains the URDF file for the robot.

---

## 🚀 Usage

This project is divided into several parts:

- **CAD**: The CAD files can be opened and edited with OpenSCAD or a compatible URDF viewer.
- **Firmware**: The firmware can be compiled and uploaded to a microcontroller using PlatformIO.
- **ROS2 Workspace**: The ROS2 workspace can be built and run using Colcon.

For more detailed instructions, please refer to the specific documentation within each subdirectory.
