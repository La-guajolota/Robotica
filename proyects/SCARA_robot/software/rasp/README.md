# 🍓 Raspberry Pi

This directory contains Python scripts for the Raspberry Pi, including a GUI and a state machine.

---

## 📂 Subdirectories

- **`guiDB/`**: Contains the source code for a dashboard that communicates with a PLC and a Firebase database.
- **`statemachine/`**: Contains the source code for a state machine that controls the robot.
- **`tests/`**: Contains test scripts for the Raspberry Pi.

---

## 🚀 Usage

The Python scripts in this directory are intended to be run on a Raspberry Pi. Make sure you have the required libraries installed before running the scripts. You can install the dependencies using the `requirements.txt` file:

```bash
pip install -r requirements.txt
```

For more detailed instructions, please refer to the specific documentation within each subdirectory.
