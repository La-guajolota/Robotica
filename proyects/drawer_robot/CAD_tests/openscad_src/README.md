# 🔩 OpenSCAD Source

This directory contains the source files for the robot's parts in OpenSCAD.

---

## 📂 Files

- **`drawer.scad`**: The main assembly file for the drawing robot.
- **`link.scad`**: A parametric template for designing a rectangular link with circular holes at the ends.
- **`pen.scad`**: A parametric template for a pencil.

---

## 🚀 Usage

The `.scad` files can be opened and edited with OpenSCAD. You can modify the parameters in the files to customize the robot's parts.
