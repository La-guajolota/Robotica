# 📐 Kinetics

This directory contains scripts for calculating the kinematics of robotic arms.

---

## 📂 Files

- **`dh.py`**: Calculates the Denavit-Hartenberg transformation matrices for kinematic analysis of robots.
- **`eslabon_obj.py`**: Defines the `Eslabon` class for creating and manipulating links in a 3D coordinate system.
- **`matriz_homogenea.py`**: Calculates the 3D homogeneous transformation matrix for a robot with multiple links.
- **`trans_rot.py`**: Provides functions to create and manipulate rotation and translation matrices in 2D.
- **`espacio de trabajo.jpg`**: An image showing the workspace of a robotic arm.

---

## 🚀 Usage

To use the scripts in this directory, you can run them from the terminal. For example, to run the Denavit-Hartenberg matrix calculator, you can use the following command:

```bash
python3 computes/kinetics/dh.py
```

For more information on how to use a specific script, please refer to the documentation within the script itself.
