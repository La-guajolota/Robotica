# ⚡️ PCB

This directory contains the PCB designs for the robot's controller, made with KiCad.

---

## 📂 Subdirectories

- **`ESP32-DEVKIT-V1/`**: Contains the KiCad symbol and footprint for the ESP32-DEVKIT-V1.
- **`pcb_controller/`**: Contains the KiCad project for the robot's controller PCB.

---

## 🚀 Usage

The PCB designs can be opened and edited with KiCad. The `pcb_controller` directory contains the main project, which you can open to view the schematic and PCB layout. You can also generate the Gerber files for manufacturing.
