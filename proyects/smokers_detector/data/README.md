# 📊 Data

This directory contains the raw and processed images for training and testing the model.

---

## 📂 Files

- **`raw.zip`**: A zip file containing the raw images, divided into `smoking` and `not_smoking` subdirectories.
- **`processed.zip`**: A zip file containing the processed images, divided into `train`, `validation`, and `test` sets.

---

## 🚀 Usage

To use the data, you need to extract the contents of the zip files. The raw images can be used to train a new model, while the processed images can be used to test the existing model.
