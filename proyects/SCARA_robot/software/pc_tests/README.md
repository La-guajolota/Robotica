# 🧪 PC Tests

This directory contains Python scripts for testing the robot's communication and vision.

---

## 📂 Subdirectories

- **`comunication_plc/`**: Contains scripts for testing the communication with a PLC using Modbus TCP/IP.
- **`vision/`**: Contains scripts for testing the robot's computer vision capabilities.

---

## 🚀 Usage

The Python scripts in this directory can be run from the terminal to test the robot's functionality. Make sure you have the required libraries installed before running the scripts.
