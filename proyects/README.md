# 🚀 Projects

This directory contains various robotics projects, from CAD designs to software implementations.

---

## 📂 Subdirectories

- **`drawer_robot/`**: A project for a drawing machine that uses computer vision and ROS2.
- **`SCARA_robot/`**: A project for a SCARA robot, including 3D parts, PCB designs, and software.
- **`smokers_detector/`**: A real-time system that detects if a person is smoking using computer vision and deep learning.

---

## 🚀 Usage

For more information on how to use the content of a specific project, please refer to the `README.md` file in that project's directory.
