# ⚡️ PCB Controller

This directory contains the KiCad project for the robot's controller PCB.

---

## 📂 Files

- **`pcb_controller.kicad_pro`**: The main KiCad project file.
- **`pcb_controller.kicad_sch`**: The schematic for the PCB.
- **`pcb_controller.kicad_pcb`**: The PCB layout.
- **`bom/`**: Contains the Bill of Materials for the PCB.
- **`production/`**: Contains the Gerber files for manufacturing the PCB.
- **`modules.pretty/`**: Contains custom footprints used in the project.
- **`pcb_controller-backups/`**: Contains backups of the project.

---

## 🚀 Usage

You can open the `pcb_controller.kicad_pro` file in KiCad to view and edit the schematic and PCB layout. The Gerber files in the `production` directory can be used to manufacture the PCB.
