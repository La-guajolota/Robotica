# 🤖 CAD Tests

This directory contains CAD files for the robot, including OpenSCAD and URDF files.

---

## 📂 Subdirectories

- **`openscad_src/`**: Contains the source files for the robot's parts in OpenSCAD.
- **`urdfs_src/`**: Contains the URDF source files for the robot, which can be used in simulations.

---

## 🚀 Usage

The files in this directory can be used to 3D print the robot's parts or to simulate the robot in a virtual environment.

- **OpenSCAD**: The `.scad` files can be opened and edited with OpenSCAD.
- **URDF**: The `.urdf.xacro` files can be used with ROS and Gazebo for simulation.
