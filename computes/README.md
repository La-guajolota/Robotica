# 🧮 Computes

This directory contains scripts and algorithms for kinematic and dynamic calculations.

---

## 📂 Subdirectories

- **`kinetics/`**: Contains scripts for calculating the kinematics of robotic arms, such as the Denavit-Hartenberg matrices.
- **`Root_finding/`**: Implements numerical methods for finding the roots of systems of non-linear equations, such as the Newton-Raphson method.

---

## 🚀 Usage

To use the scripts in this directory, you can run them from the terminal. For example, to run the Denavit-Hartenberg matrix calculator, you can use the following command:

```bash
python3 computes/kinetics/dh.py
```

For more information on how to use a specific script, please refer to the documentation within the script itself.
