# 🤖 URDF Source

This directory contains the URDF source files for the robot, which can be used in simulations.

---

## 📂 Files

- **`my_car.urdf.xacro`**: A Xacro file to define a simple mobile robot named "my_car".
- **`my_robot.urdf.xacro`**: A URDF file to define a simple robot named "my_robot" with two links and a revolute joint.
- **`modularization/`**: Contains a modularized version of the `my_car.urdf.xacro` file.

---

## 🚀 Usage

The `.urdf.xacro` files can be used with ROS and Gazebo for simulation. To use them, you need to have a ROS environment set up.
