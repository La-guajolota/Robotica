# 🦾 SCARA Robot

This project is for a SCARA robot, including 3D parts, PCB designs, and software.

---

## 📂 Subdirectories

- **`3D_piezas/`**: Contains the 3D parts of the robot in a zip file.
- **`diagramas/`**: Contains a PDF diagram of the robot.
- **`PCB/`**: Contains the PCB designs for the robot's controller, made with KiCad.
- **`software/`**: Contains the software for the robot, including a ROS2 workspace and firmware for an ESP32.

---

## 🚀 Usage

This project is divided into several parts:

- **3D Parts**: The 3D parts can be extracted from the zip file and 3D printed.
- **PCB**: The PCB designs can be opened and edited with KiCad.
- **Software**: The software is divided into a ROS2 workspace and firmware for an ESP32. For more detailed instructions, please refer to the specific documentation within each subdirectory.
