# ⚡️ ESP32-DEVKIT-V1

This directory contains the KiCad symbol and footprint for the ESP32-DEVKIT-V1.

---

## 📂 Files

- **`ESP32-DEVKIT-V1.kicad_sym`**: The KiCad symbol for the ESP32-DEVKIT-V1.
- **`ESP32-DEVKIT-V1.step`**: The 3D model of the ESP32-DEVKIT-V1.
- **`how-to-import.htm`**: A guide on how to import the symbol and footprint into KiCad.
- **`MODULE_ESP32_DEVKIT_V1.kicad_mod`**: The KiCad footprint for the ESP32-DEVKIT-V1.

---

## 🚀 Usage

You can use these files to add the ESP32-DEVKIT-V1 to your KiCad projects. The `how-to-import.htm` file provides instructions on how to do this.
