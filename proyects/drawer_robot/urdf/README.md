# 🤖 URDF

This directory contains the URDF file for the robot.

---

## 📂 Files

- **`robot.urdf.xacro`**: A URDF file that defines a simple 2-DOF robotic arm.

---

## 🚀 Usage

The `.urdf.xacro` file can be used with ROS and Gazebo for simulation. To use it, you need to have a ROS environment set up.
