# 🧠 Root Finding

This directory implements numerical methods for finding the roots of systems of non-linear equations.

---

## 📂 Files

- **`BisectionMethod.py`**: Implements the bisection method to find the roots of a function.
- **`Newton_Raphson_multiVar.py`**: Implements the Newton-Raphson method to solve a system of non-linear equations.
- **`Newton_Raphson_multiVar2.py`**: Another example of the Newton-Raphson method for a system of non-linear equations.
- **`Newton-Raphson.py`**: Implements the Newton-Raphson method to find the roots of a single variable function.
- **`RootFindingStatement.py`**: Examples of using the `scipy.optimize.fsolve` function to find the roots of functions.
- **`Tolerance.py`**: A simple script to calculate the error between two values.
- **`jacobn_matrix_inverse_kemats.jpeg`**: An image with a matrix.
- **`links.txt`**: A file with some links.

---

## 🚀 Usage

To use the scripts in this directory, you can run them from the terminal. For example, to run the Newton-Raphson method for a system of non-linear equations, you can use the following command:

```bash
python3 computes/Root_finding/Newton_Raphson_multiVar.py
```

For more information on how to use a specific script, please refer to the documentation within the script itself.
