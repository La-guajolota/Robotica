# 📦 Modularization

This directory contains a modularized version of the `my_car.urdf.xacro` file.

---

## 📂 Files

- **`common_properties.xacro`**: Contains common properties for the robot, such as materials.
- **`mobile_base.xacro`**: Contains the definition of the mobile base of the robot.
- **`my_car.urdf.xacro`**: The main file that includes the other two files to create the complete robot.

---

## 🚀 Usage

This modularized version of the robot can be used in the same way as the non-modularized version. The main advantage is that it is easier to maintain and modify.
