# 🧊 3D Parts

This directory contains the 3D parts of the robot in a zip file.

---

## 📂 Files

- **`Planos scara.zip`**: A zip file containing the 3D plans for the SCARA robot.

---

## 🚀 Usage

To use the 3D parts, you need to extract the contents of the zip file. The files can then be used for 3D printing or for visualization in a CAD program.
