# 📝 Practicas

This directory contains practice notebooks and scripts.

---

## 📂 Files

- **`hibrido.ipynb`**: A Jupyter notebook that imports a function from a `utils.io` module.
- **`manos.py`**: A script that uses OpenCV and the `cvzone` library to detect hands in real-time through a webcam.

---

## 🚀 Usage

The Python scripts and notebooks in this directory can be run to see the results of the computer vision algorithms. Make sure you have the required libraries installed before running the scripts.
