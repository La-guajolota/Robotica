# 🧪 Tests

This directory contains test scripts for the Raspberry Pi.

---

## 📂 Subdirectories

- **`pc_computer_vision/`**: Contains test scripts for computer vision on a PC.
- **`plc_communication/`**: Contains test scripts for PLC communication.
- **`rasp_computer_vision/`**: Contains test scripts for computer vision on a Raspberry Pi.

---

## 🚀 Usage

The Python scripts in this directory can be run from the terminal to test the robot's functionality. Make sure you have the required libraries installed before running the scripts.
